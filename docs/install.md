# kkilog 설치 안내

안드로이드 폰에서만 쓸 수 있어요. Play 스토어가 아니라 파일(APK)로 직접 설치해요.

## 받을 것
- **설치 링크**: 운영자가 보내 준 링크
- **접속 코드**: 운영자가 따로 보내 준 코드. 다른 사람에게 보여 주지 마세요.

## 설치
1. 폰에서 설치 링크를 열고 **APK를 내려받아요**.
2. 내려받은 파일을 눌러 설치해요.
   - "출처를 알 수 없는 앱" 안내가 나오면 **설정**을 눌러, 지금 쓰는 앱(Chrome이나 내 파일 등)의 **이 출처 허용**을 켜고 뒤로 돌아와요.
   - "Play 프로텍트" 경고가 나오면 **세부정보 더보기 → 무시하고 설치**를 눌러요. Play 스토어에 올리지 않은 앱이라 나오는 경고예요.
3. **kkilog**를 열고 **접속 코드**를 넣어요.
4. 처음 한 번 프로필(키, 몸무게, 목표 등)을 입력하면 하루 목표 칼로리가 정해져요.

## 쓰다 보면
- **업데이트**: 대부분 자동이에요. 앱을 완전히 껐다 켜면 새 버전이 받아지고, 그 다음 실행부터 적용돼요.
- **새 설치 파일을 받았을 때**: 그냥 덮어 설치하면 돼요. 기록은 그대로 남아 있어요.
- **폰을 바꾸거나 앱을 지웠을 때**: 다시 설치하고 같은 접속 코드를 넣으면 기록이 그대로 돌아와요.
- **접속 코드를 잃어버렸을 때**: 운영자에게 새 코드를 받아요. 예전 코드는 막히지만 기록은 그대로예요.

## 알아 둘 것
- 사진과 기록은 운영자의 서버에 저장돼요.
- 칼로리·영양 추정과 조언은 Google Gemini(무료 버전)가 만들어요. 이때 끼니 사진·설명과, 조언을 위한 최근 일주일 기록 요약·목표·체중 추세가 Google로 전송돼요. 무료 버전은 Google이 서비스 개선에 입력을 쓸 수 있어요.
- 추정치는 ±20~30% 정도 틀릴 수 있어요. 정확한 숫자보다 흐름을 보는 용도예요.
